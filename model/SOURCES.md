# Sources read for the Model tab

Collected 2026-10-31. "Read" means the full text (or the named sections) was downloaded and read as text;
"snippet" means only an abstract, catalogue record or search-engine excerpt was seen. Local copies of the
PDFs used are not kept in the repository; the URLs below were live on the collection date. Every coefficient
quoted in `model_spec.md` carries a tag naming the document and the equation/table it was taken from.
